# Инструкции по отладке проблемы с загрузкой

## Что изменено (версия 11.3)

### 1. Добавлены таймауты для запросов к Supabase
- Каждый запрос теперь имеет таймаут 10 секунд
- Если запрос не завершится за 10 секунд, появится понятная ошибка
- Это предотвращает бесконечное ожидание

### 2. Улучшено логирование
Теперь в консоли вы увидите:
```
[Init] CONFIG loaded: ...
[Init] Creating Supabase client...
[Init] ✓ Supabase client created successfully
[loadUserData] Starting with userId: ...
[loadUserData] Fetching all data from Supabase in parallel...
[Query CLIENT] Completed in XXXms OK
[Query BOOKING] Completed in XXXms OK
[Query RENTAL] Completed in XXXms OK
[loadUserData] All queries completed in XXXms
```

### 3. Улучшена обработка ошибок
- Добавлена кнопка "Обновить страницу" при ошибке
- Показывается подсказка про VPN
- Подробное описание ошибки

## Как протестировать

### Вариант 1: Основное приложение
1. Откройте `index.html`
2. Откройте консоль браузера (F12)
3. Смотрите логи - они покажут, на каком этапе происходит задержка

### Вариант 2: Тестовая страница
1. Откройте `test-connection.html` в браузере
2. Нажмите кнопку "Запустить тест"
3. Вы увидите детальный отчет:
   - Проверка CONFIG
   - Проверка Supabase SDK
   - Создание клиента
   - Тестовый запрос
   - Время выполнения каждого шага

## Что смотреть в логах

### Если видите `[Query XXX] Completed in YYYms OK`:
- Это нормально, запрос выполнился успешно
- Обратите внимание на время (YYYms)
- Более 3000ms - это медленно, проблема в сети

### Если видите `timeout after 10000ms`:
- Запрос к Supabase завис
- Скорее всего проблема в интернет-соединении
- Попробуйте включить VPN

### Если видите `[Init] Supabase library not loaded! Retrying...`:
- Файл supabase.min.js не загрузился
- Проверьте, что файл существует в папке site/
- Проверьте консоль на ошибки 404

## Типичные проблемы и решения

### Проблема: Бесконечная загрузка без ошибок
**Решение:**
1. Откройте консоль
2. Найдите последнее сообщение с [Query ...]
3. Если запрос не завершился за 10 сек - проблема в сети
4. Включите VPN и обновите страницу

### Проблема: Ошибка "CLIENT query timeout"
**Решение:**
- Проблема с подключением к Supabase
- Supabase может быть медленным из России
- Варианты:
  1. Включить VPN
  2. Увеличить таймаут до 30 секунд (в коде: изменить 10000 на 30000)
  3. Использовать прокси-сервер

### Проблема: "Supabase library not loaded"
**Решение:**
1. Проверьте, что файл `site/supabase.min.js` существует
2. Размер файла должен быть ~102KB
3. Если файла нет, скачайте:
   ```bash
   curl -o site/supabase.min.js https://cdn.jsdelivr.net/npm/@supabase/supabase-js@2.41.0/dist/umd/supabase.min.js
   ```

## Следующие шаги

1. **Сначала** откройте `test-connection.html` и запустите тест
2. Скопируйте все логи из консоли
3. Если тест показывает время > 5000ms - проблема в скорости сети
4. Если тест показывает timeout - проблема в доступности Supabase

## Временное решение (если очень срочно)

Если нужно срочно запустить, можно временно убрать таймауты:

1. Откройте `site/index.html`
2. Найдите строку `10000,` (около строки 1053, 1067, 1081)
3. Замените на `60000,` (60 секунд)
4. Сохраните и обновите страницу

Но это не решит проблему - просто даст больше времени на ожидание.
