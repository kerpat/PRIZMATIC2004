# 📷 Тестирование камеры и QR-сканера

## 🎯 Способы тестирования

### 1. Эмулятор Android Studio (с настройкой камеры)

#### Шаг 1: Настройте виртуальное устройство
1. Откройте **Android Studio** → **Device Manager** (или AVD Manager)
2. Нажмите на иконку **редактирования** (карандаш) у вашего эмулятора
3. Нажмите **Show Advanced Settings**
4. Прокрутите до раздела **Camera**:
   - **Front Camera**: выберите **Webcam0** (или **Emulated**)
   - **Back Camera**: выберите **VirtualScene** или **Webcam0**

#### Шаг 2: Запустите эмулятор
```bash
# Из корня проекта
cd android
./gradlew installDebug

# Или запустите через Android Studio
```

#### Шаг 3: Тестирование в эмуляторе
1. **С VirtualScene (виртуальная сцена)**:
   - В эмуляторе нажмите кнопку **"..."** (расширенные настройки)
   - Выберите **Camera** → **Virtual scene**
   - Используйте **WASD** для управления виртуальной камерой
   - Поместите QR-код в виртуальной сцене

2. **С Webcam (веб-камера компьютера)**:
   - Эмулятор будет использовать веб-камеру вашего компьютера
   - Поднесите QR-код к камере компьютера
   - Должно работать как на реальном устройстве

### 2. Реальное устройство (РЕКОМЕНДУЕТСЯ) ✅

#### Подключите Android устройство по USB:
```bash
# 1. Включите режим разработчика на телефоне:
#    Настройки → О телефоне → Нажмите 7 раз на "Номер сборки"

# 2. Включите отладку по USB:
#    Настройки → Для разработчиков → Отладка по USB

# 3. Проверьте подключение:
adb devices

# 4. Установите APK:
adb install android/app/build/outputs/apk/debug/app-debug.apk

# Или из Android Studio:
cd android
./gradlew installDebug
```

### 3. Fallback режим (загрузка изображения)

Если камера недоступна, приложение автоматически предложит:
- Загрузить фото с QR-кодом из галереи
- Сделать фото QR-кода через камеру телефона

Это работает везде, включая эмуляторы без камеры!

## 🧪 Как проверить работу

### В приложении:
1. Откройте приложение PRIZMATIC
2. Нажмите кнопку **"Сканировать QR"** или иконку сканера
3. **Что должно произойти**:
   - ✅ Откроется модальное окно с видео камеры
   - ✅ Приложение запросит разрешение на камеру (первый раз)
   - ✅ После разрешения должен отобразиться поток с камеры
   - ✅ При наведении на QR-код он должен распознаться автоматически

### Если камера не работает в эмуляторе:
1. Проверьте настройки AVD (см. выше)
2. Перезапустите эмулятор
3. Используйте реальное устройство для тестирования

## 🔧 Отладка проблем

### Проверка разрешений в logcat:
```bash
# Смотрите логи приложения
adb logcat | grep -i "camera\|permission\|prizmatic"
```

### Если камера не запрашивает разрешение:
```bash
# Вручную дайте разрешение:
adb shell pm grant ru.prizmatic.app android.permission.CAMERA
```

### Если приложение падает:
```bash
# Смотрите crash логи:
adb logcat *:E
```
