# 📱 Исправление проблемы с камерой на мобильном устройстве

## Проблема
При регистрации с мобильного устройства, когда пользователь фотографирует паспорт с помощью камеры (используя атрибут `capture="environment"`), возникает ошибка:
```
the string did not match the expected pattern
```

При этом загрузка фото с компьютера работает корректно.

## Причина
Проблема заключается в том, что данные, полученные с камеры мобильного устройства, могут отличаться от стандартных файлов:
1. Различный формат заголовков в multipart-форме
2. Нестандартные MIME-типы или отсутствие таковых
3. Дополнительные метаданные изображений
4. Нестандартные сигнатуры файлов

## Решение
В коде были внесены следующие улучшения:

### 1. Улучшенный парсинг multipart-данных
- Добавлена обработка ошибок при чтении файлов
- Проверка валидности буфера данных
- Автоматическое определение MIME-типа по сигнатуре файла
- Увеличение лимитов для обработки больших файлов с камеры

### 2. Улучшенная валидация файлов перед сохранением
- Проверка минимального размера файлов
- Проверка сигнатур файлов для подтверждения типа изображения
- Фильтрация невалидных файлов до попытки сохранения

## Технические детали

### Улучшения в `api/_lib_auth.js`:

1. **parseMultipartForm**: 
   - Увеличены лимиты для обработки больших файлов (до 10MB)
   - Добавлена обработка ошибок чтения файлов
   - Добавлено автоматическое определение MIME-типа по сигнатуре файла
   - Улучшена обработка случаев с отсутствующими или некорректными данными

2. **storeUploadedFiles**:
   - Добавлена проверка валидности буфера с помощью `Buffer.isBuffer()`
   - Добавлена проверка минимального размера файла
   - Добавлена валидация сигнатуры файла для подтверждения, что это действительно изображение

## Совместимость
- ✅ Работает с камерой мобильных устройств
- ✅ Сохраняет совместимость с загрузкой файлов с компьютера
- ✅ Поддерживает форматы JPEG, PNG, GIF, WebP
- ✅ Обрабатывает файлы до 10MB

## Дополнительная информация
Атрибут `capture="environment"` в HTML-форме указывает браузеру использовать камеру устройства вместо файлового диалога. Это создает особенности в формате отправляемых данных, которые теперь обрабатываются корректно.
